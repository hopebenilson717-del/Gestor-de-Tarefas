# TaskFlow — Gestor de tarefas

Projecto simples de gestão de tarefas feito com HTML, CSS e JavaScript puro.

## Como executar
1. Extrai o ficheiro ZIP.
2. Abre a pasta `gestor-de-tarefas`.
3. Abre `index.html` no navegador (Chrome, Firefox, etc.).

Não precisa de servidor, instalação ou dependências.

## Funcionalidades
- Criar tarefas com título, descrição, prioridade e data limite.
- Editar e eliminar tarefas.
- Marcar tarefas como concluídas e voltar a abrir.
- Filtrar por todas, por fazer e concluídas.
- Pesquisar pelo título ou descrição.
- Ordenar por data de criação ou data limite.
- Guardar automaticamente no `localStorage` do navegador.

## Estrutura
- `index.html` — estrutura da aplicação.
- `style.css` — aparência e adaptação a telemóveis.
- `script.js` — funcionalidades e armazenamento local.

## Nota
As tarefas ficam guardadas apenas no navegador e dispositivo onde foram criadas.
